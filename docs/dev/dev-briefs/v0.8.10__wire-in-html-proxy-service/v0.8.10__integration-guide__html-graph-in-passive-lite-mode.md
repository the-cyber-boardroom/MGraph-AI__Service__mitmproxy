# HTML Graph "Passive-Lite" Mode - Integration Guide

## Overview

This implements a new `mitm-mode=cache` mode that uses HTML Graph for passive HTML caching:
- **Cache-first**: Check cache on request, serve if found
- **Store on miss**: If cache miss, fetch from origin and store

```
┌─────────────────────────────────────────────────────────────────────┐
│                     mitm-mode=cache Flow                            │
└─────────────────────────────────────────────────────────────────────┘

Browser sets Cookie: mitm-mode=cache
    │
    ▼
┌─────────────────────────────────────────┐
│  Request Phase                          │
│  └── Check HTML Graph cache             │
│       ├── HIT  → Return cached HTML     │
│       └── MISS → Continue to upstream   │
└─────────────────────────────────────────┘
    │ (only if MISS)
    ▼
┌─────────────────────────────────────────┐
│  Response Phase                         │
│  └── Store HTML in HTML Graph           │
│       └── Return original HTML          │
└─────────────────────────────────────────┘
```

## Integration Steps

### 1. Create new directory structure

```bash
mkdir -p mgraph_ai_service_mitmproxy/service/html_graph
touch mgraph_ai_service_mitmproxy/service/html_graph/__init__.py
```

### 2. Copy new files

```bash
# Copy the new files to their locations:
cp consts__html_graph.py          mgraph_ai_service_mitmproxy/service/consts/
cp HTML_Graph__Service__Client.py mgraph_ai_service_mitmproxy/service/html_graph/
```

### 3. Update Enum__HTML__Transformation_Mode

Add to `mgraph_ai_service_mitmproxy/schemas/html/Enum__HTML__Transformation_Mode.py`:

```python
# Add to enum values:
CACHE = "cache"

# Add to from_cookie_value mapping:
"cache": cls.CACHE,

# Modify is_active() to exclude CACHE:
def is_active(self) -> bool:
    inactive_modes = {
        Enum__HTML__Transformation_Mode.OFF,
        Enum__HTML__Transformation_Mode.CACHE,  # <-- Add this
    }
    return self not in inactive_modes
```

### 4. Replace service files

Replace the request and response services with the modified versions.

| `HTML_GRAPH__KEY_VALUE` | (none) | Auth header value |

## Usage

### Set the cookie in browser:

```javascript
document.cookie = "mitm-mode=cache; path=/";
```

### Or via curl:

```bash
curl -H "Cookie: mitm-mode=cache" https://example.com
```

### Clear the cookie:

```javascript
document.cookie = "mitm-mode=off; path=/";
```

---

## Response Headers

### On Cache HIT (served from cache):

```
x-cache-source: html-graph
x-cache-key: example.com/about
x-cache-id: aa27fb2a-f8d2-44aa-adca-5dc1736fdddd
```

### On Cache MISS (stored after fetch):

```
x-html-graph-stored: true
x-html-graph-cache-key: example.com/about
x-html-graph-cache-id: aa27fb2a-f8d2-44aa-adca-5dc1736fdddd
x-html-graph-chars: 12345
```

---

## Coexistence with Existing Modes

The cache mode runs **alongside** existing transformation modes:

| Cookie Value | Behavior |
|--------------|----------|
| `mitm-mode=off` | Pass through (no action) |
| `mitm-mode=cache` | **NEW**: HTML Graph cache |
| `mitm-mode=xxx` | Transform all text to xxx |
| `mitm-mode=xxx-negative` | Transform negative sentiment |
| etc. | (existing modes work unchanged) |

## Testing

### Test cache miss (first request):

```bash
curl -v -H "Cookie: mitm-mode=cache" https://example.com/test
# Should see: x-html-graph-stored: true
```

### Test cache hit (second request):

```bash
curl -v -H "Cookie: mitm-mode=cache" https://example.com/test
# Should see: x-cache-source: html-graph
```

### Verify in HTML Graph:

```bash
curl https://html-graph.dev.mgraph.ai/flet-html-domain/html/load/mitmproxy-cache/key/example.com/test
# Should return: {"found": true, "html": "..."}
```
