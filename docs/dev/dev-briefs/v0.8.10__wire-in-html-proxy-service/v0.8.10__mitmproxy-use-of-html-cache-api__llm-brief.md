# LLM Brief: HTML Cache API for MitmProxy

## What Is This?

The HTML Graph API provides a centralized cache for storing and retrieving HTML content by URL. It acts as a persistent HTML store that any service can write to and read from.

**Base URL:** `https://html-graph.dev.mgraph.ai`

## Why Use It?

When building a MitmProxy addon that intercepts web traffic, you often want to:

1. **Cache HTML for offline access** - Store pages as they're visited, retrieve later without hitting origin
2. **Track page versions over time** - Each store operation preserves content with timestamps
3. **Share cached content across services** - One service caches, another consumes
4. **Analyze HTML separately** - Store raw HTML now, process/transform later via FLeT pipelines

**The problem:** MitmProxy runs locally and transiently. If you restart, your cache is gone. If you want another service to access the HTML, it can't.

**The solution:** Store HTML in a remote, persistent cache indexed by URL. Any service with the URL can retrieve the HTML later.

## How It Works

```
┌─────────────────┐         ┌──────────────────────────────────┐
│   MitmProxy     │         │     HTML Graph API               │
│                 │         │  html-graph.dev.mgraph.ai        │
│  1. Intercept   │         │                                  │
│     request to  │         │  ┌────────────────────────────┐  │
│     example.com │         │  │  Namespace: mitmproxy-cache│  │
│                 │         │  │                            │  │
│  2. Fetch HTML  │  ────►  │  │  example.com/  │  │
│     from origin │  Store  │  │    ├── root     (html)     │  │
│                 │         │  │    ├── about    (html)     │  │
│  3. Store HTML  │         │  │    └── contact  (html)     │  │
│     with URL    │  ◄────  │  │                            │  │
│                 │  Load   │  └────────────────────────────┘  │
│  4. Later:      │         │                                  │
│     Load cached │         │                                  │
└─────────────────┘         └──────────────────────────────────┘
```

**Key concept:** URLs are converted to cache keys using `Url__To__Cache_Key`:
- `https://example.com/about` → `example.com/about`

This means you can store and retrieve HTML using the original URL - no need to track cache IDs.

## Quick Start

### 1. Store HTML (after intercepting)

```python
from mgraph_ai_serverless.utils.Url__To__Cache_Key import Url__To__Cache_Key
import requests

# Convert URL to cache_key
url       = "https://example.com/about"
cache_key = Url__To__Cache_Key.from_url(url)  # → "example.com/about"

# Store HTML
response = requests.post(
    f"https://html-graph.dev.mgraph.ai/flet-html-domain/html/store/my-namespace/key/{cache_key}",
    json={"html": "<html><body>Hello World</body></html>"}
)

result = response.json()
# {
#     "success": true,
#     "cache_id": "aa27fb2a-f8d2-44aa-adca-5dc1736fdddd",
#     "cache_key": "example.com/about",
#     "cache_hash": "c593da9e13abd824",
#     "char_count": 42
# }
```

### 2. Load HTML (by URL)

```python
from mgraph_ai_serverless.utils.Url__To__Cache_Key import Url__To__Cache_Key
import requests

# Convert URL to cache_key
url       = "https://example.com/about"
cache_key = Url__To__Cache_Key.from_url(url)

# Load HTML
response = requests.post(
    f"https://html-graph.dev.mgraph.ai/flet-html-domain/html/load/my-namespace/key/{cache_key}"
)

result = response.json()
# {
#     "success": true,
#     "found": true,
#     "html": "<html><body>Hello World</body></html>",
#     "cache_id": "aa27fb2a-f8d2-44aa-adca-5dc1736fdddd",
#     "cache_key": "example.com/about",
#     "char_count": 42
# }
```

## URL to Cache Key Conversion

The `Url__To__Cache_Key` utility converts URLs to cache-friendly paths:

| URL | Cache Key |
|-----|-----------|
| `https://example.com` | `example.com/root` |
| `https://example.com/` | `example.com/root` |
| `https://example.com/about` | `example.com/about` |
| `https://example.com/blog/post-1` | `example.com/blog/post-1` |
| `https://sub.example.com/page` | `sub.example.com/page` |
| `https://example.com/page?q=1` | `example.com/page` (query stripped) |

## API Reference

### Store HTML

```
POST /flet-html-domain/html/store/{namespace}/key/{cache_key}
Content-Type: application/json

{"html": "<html>...</html>"}
```

**Response:**
```json
{
    "success": true,
    "cache_id": "uuid",
    "cache_key": "example.com/about",
    "cache_hash": "hash",
    "char_count": 1234
}
```

### Load HTML

```
POST /flet-html-domain/html/load/{namespace}/key/{cache_key}
```

**Response (found):**
```json
{
    "success": true,
    "found": true,
    "html": "<html>...</html>",
    "cache_id": "uuid",
    "cache_key": "example.com/about",
    "char_count": 1234
}
```

**Response (not found):**
```json
{
    "success": true,
    "found": false
}
```

## MitmProxy Integration Example

```python
from mitmproxy import http
from mgraph_ai_serverless.utils.Url__To__Cache_Key import Url__To__Cache_Key
import requests

BASE_URL  = "https://html-graph.dev.mgraph.ai"
NAMESPACE = "mitmproxy-cache"

class HtmlCacheAddon:
    
    def response(self, flow: http.HTTPFlow):
        """Cache HTML responses after fetching from origin."""
        
        # Only cache HTML responses
        content_type = flow.response.headers.get("content-type", "")
        if "text/html" not in content_type:
            return
        
        # Get URL and HTML
        url  = flow.request.pretty_url
        html = flow.response.text
        
        # Convert URL to cache_key and store
        cache_key = Url__To__Cache_Key.from_url(url)
        requests.post(
            f"{BASE_URL}/flet-html-domain/html/store/{NAMESPACE}/key/{cache_key}",
            json={"html": html}
        )
    
    def request(self, flow: http.HTTPFlow):
        """Check cache before fetching from origin."""
        
        url       = flow.request.pretty_url
        cache_key = Url__To__Cache_Key.from_url(url)
        
        # Check cache
        response = requests.post(
            f"{BASE_URL}/flet-html-domain/html/load/{NAMESPACE}/key/{cache_key}"
        )
        result = response.json()
        
        if result.get("found"):
            # Return cached HTML, skip origin
            flow.response = http.Response.make(
                200,
                result["html"],
                {"Content-Type": "text/html"}
            )

addons = [HtmlCacheAddon()]
```
